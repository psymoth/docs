## Enhancements

### Chinese Trellis Project Docs

New projects generated by `trellis init` now default human-readable Trellis docs to Chinese while preserving file names, commands, API names, JSON keys, status values, symbols, and Trellis technical terms.

| Area | Change |
| --- | --- |
| `AGENTS.md` | States the Chinese default for collaboration and Trellis docs. |
| `.trellis/workflow.md` | Adds the human-readable language policy. |
| `.trellis/spec/**/index.md` | Replaces the old English-only documentation rule. |
| `.trellis/tasks/00-bootstrap-guidelines/prd.md` | Guides the bootstrap AI in Chinese. |
| `.trellis/tasks/00-join-*/prd.md` | Guides joiner onboarding in Chinese. |

### Codex Trellis Doc Organizer

Codex-enabled Trellis projects now receive `.codex/skills/trellis-doc-organizer/SKILL.md`.

The skill organizes existing Trellis artifacts in place so downstream agents can read less context and avoid stale or duplicated facts across `prd.md`, `design.md`, `implement.md`, `research/*.md`, and `.trellis/spec/**`.

It keeps source documents by default, lowers stale research authority with statuses such as `historical`, `superseded`, or `pointer`, and avoids creating a new summary/source-map layer unless explicitly requested.

## Upgrade

```bash
npm install -g psymoth@beta
trellis update
```

Run `trellis update` in Codex-enabled projects to install `.codex/skills/trellis-doc-organizer/SKILL.md`. No migration command is required.
