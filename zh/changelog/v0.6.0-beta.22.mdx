## Enhancements

### psymoth npm packages

Beta distribution 现在把 CLI 发布为 `psymoth`，core SDK 发布为 `psymoth-core`。

| Surface | New package |
| --- | --- |
| CLI install | `npm install -g psymoth@beta` |
| Core root import | `psymoth-core` |
| Channel API | `psymoth-core/channel` |
| Task API | `psymoth-core/task` |
| Mem API | `psymoth-core/mem` |

Release scripts、`trellis upgrade`、session update hints、README badges、packed CLI dependency checks 和 `.github/workflows/publish.yml` 现在都使用新的 package names。

### trellis-goal Codex native bridge

`trellis-goal` 现在准备 Trellis task artifacts，并通过 `create_goal` 把无人值守执行交给 Codex native goal mode。

- Goal Contract source: `prd.md`
- Technical boundary source: `design.md`
- Evidence checkpoints: `implement.md`
- Native goal state: `create_goal`、`get_goal`、`update_goal`

`implement.md` checkpoints 是证据和恢复路标，不是本地 queue 或单独的 execution loop。

## Bug Fixes

### task.py goal checkpoints

`task.py goal-info` 汇总 Trellis goal progress 时现在只解析 `### Checkpoint N:` headings。

`task.py mark-goal --cadence` 接受 `checkpoint-bounded` 和 `run-to-completion`；默认值现在是 `checkpoint-bounded`。

## Upgrade

```bash
npm install -g psymoth@beta
trellis update
```

不需要运行 migration command。
